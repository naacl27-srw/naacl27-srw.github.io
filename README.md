# NAACL 2027 Student Research Workshop

Static website. Edit `index.html`, `author-guidelines.html`, and `assets/css/style.css`; preview locally with
`python3 -m http.server 8765` and visit http://localhost:8765.

## Content references

Updated September 10, 2026 using the organizers' supplied CFP and timeline.
The public schedule includes mentorship, submission, acceptance, camera-ready,
and conference dates. Grant notification is labeled tentative; the grant
application deadline and exact workshop date remain TBD. Internal reviewing,
CFP reminder, contingency, and proceedings-production dates are not published.
The workshop-specific OpenReview URL still needs to be supplied.

- `author-guidelines.html` hosts the six detailed author-policy sections locally.
  The index links open the relevant sections in new tabs. Text is reused from
  the [MIT-licensed source](https://github.com/naacl2025-srw/naacl2025-srw.github.io/blob/main/author.md);
  see `THIRD_PARTY_NOTICES.md` for the retained license notice.
  Changes are limited to the workshop name/year, heading capitalization, a
  missing final period, and links to the existing ACL/ACM policy resources.
  The sentence freezing authorship after an abstract deadline is omitted because
  no separate abstract deadline has been announced for 2027. Historical dates
  and page limits are not copied.
- [ACL templates](https://github.com/acl-org/ACLPUB/tree/master/templates) and
  [formatting documentation](https://acl-org.github.io/ACLPUB/formatting.html).
- [Student mentorship form](https://forms.gle/8MT3nQ3nhjGPcjdS9).
- [Mentor/reviewer respondent form](https://docs.google.com/forms/d/e/1FAIpQLSfvZ0bjUWfC56kJcdPS6WUtGZrHaBPmIbcsY8Fpsv4SsEPKjg/viewform):
